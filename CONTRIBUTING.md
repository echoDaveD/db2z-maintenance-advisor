# Contributing

Contributions are welcome.

Before opening an issue or pull request:

1. Remove company names, internal subsystem IDs, dataset HLQs, credentials, and application-sensitive data.
2. State the Db2 for z/OS version, function level, and relevant maintenance context.
3. For utility problems, include sanitized DSNU messages and the generated control statement.
4. For recommendation problems, include the effective ACCOXPAR values and a sanitized ACCOXOUT row.
5. Prefer PREVIEW reproductions where possible.

Code changes should preserve the fixed-width ACCOXOUT contract or update both REXX programs and the documentation together.
