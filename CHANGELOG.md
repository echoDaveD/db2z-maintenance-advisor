# Changelog

## 0.1.0 - 2026-08-25

Initial public reference package.

- DSNACCOX policy driver for Db2 for z/OS 13.
- Recommendation reason diagnostics.
- Local REORG guardrails and object exclusions.
- RUNSTATS profile-update detection and PROFILE_TABLE output.
- DB2UTGEN generation of REORG, incremental COPY, full COPY, and RUNSTATS jobs.
- RUNSTATSPROFILE support.
- Preview-oriented sample configuration and JCL.
